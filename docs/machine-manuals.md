# Current machine manual sources

The ten replacement operator PDFs supplied on September 20, 2026 are catalogued
with SHA-256 checksums and page counts. Machine specs opens the installed copies.
Four models match their manual covers directly. The owner confirmed PT 331SC as
PT 33SC and PT 9375BSC as PT 9375SCC Supercut. The remaining four manuals are
available as background references, without assigning them to another model.

Reviewed notes use one-based PDF page numbers. They cover stock specifications,
registration measurement origins, crease-depth conventions and barcode structure.
Code 39 JJJQQ and the interpretation of QQ as sheet count are supported by the
8336 and 9375 manuals. Current barcode sizing and the 52 mm right-edge offset
remain owner-specified; the 9375 diagram shows different position references.

Unresolved specification conflicts are visible in Machine specs and contextual
tooltips: inconsistent sheet-size equivalents, differing gutter descriptions,
manual versus numeric crease-depth adjustment, and optional tooling counts.
Do not silently substitute a printed conversion or optional configuration for the
installed machine. Existing owner-configured geometry limits remain provisional.
Unambiguous thickness ranges have been added to the PT 33SC, PT 331SCC and
PT 331SCC Air profiles (0.15–0.35 mm), and Supercut (0.15–0.4 mm). Profile versions
are advanced to 1.0.1; historical saved snapshots remain unchanged.
The four-strike-position application limit is retained despite the 9375 manual
listing eight assemblies. Physical validation remains required.

These PDFs retain their authorship and notices and are not Apache-2.0 code.
