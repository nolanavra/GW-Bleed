# Contributing

Contributions use Apache-2.0 for project-owned source. Sign off every commit with
`git commit -s` to certify the Developer Certificate of Origin 1.1:
https://developercertificate.org/ . Do not submit material you cannot license.

Use a branch and pull request. At least one maintainer other than the author
must review production changes. Never add customer PDFs, personal paths, secrets,
or copied dependency source without its provenance/license. Use synthetic test
artwork. Run the full Windows suite and add regression cases for output changes.
Machine-geometry changes require physical revalidation before production approval.

Public repository and maintainer accounts have not yet been supplied. Local
commits do not imply a hosted repository, branch protection, or external CI run.
