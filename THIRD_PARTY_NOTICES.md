# Third-party licensing

Apache-2.0 applies to project-owned code, not the entire dependency bundle.
Bundled machine manuals under `gw_imposition/resources/manuals` retain their
original authorship and notices and are not relicensed as Apache-2.0. The local
catalog records their original filenames and checksums; see `docs/machine-manuals.md`.
The release inventory and copied license texts generated by
`tools/dependency_inventory.py` accompany each packaged artifact.

| Component | Role | License review basis |
|---|---|---|
| CPython | Runtime | PSF and bundled third-party notices |
| PySide6 / Shiboken / Qt | UI | LGPLv3/GPL/commercial, module-specific; ship only required modules |
| pypdf | PDF structure and vector writing | BSD-3-Clause |
| pypdfium2 | PDFium binding | Apache-2.0 / BSD-3-Clause; retain binding notices |
| PDFium and bundled codecs/fonts | PDF rendering/flattening | BSD-style and build-specific third-party licenses |
| Pillow | Image encoding | HPND and bundled library notices |
| python-barcode | Barcode geometry | MIT |
| ReportLab | Test fixture generation only | BSD-style; excluded from desktop runtime |
| ZXing-C++ Python binding | Independent test decoding only | Apache-2.0; excluded from desktop runtime |

The exact installed wheel license texts govern. pypdfium2 wheels contain
BUILD_LICENSES for PDFium's native dependencies; do not omit these.
Qt LGPL redistribution/source/replacement requirements require a packaged-build
review before public binaries ship. This repository does not claim a completed
license audit. Test/deployment tools retain their own licenses.

The pre-migration Git tag is an INTERNAL PyMuPDF-dependent baseline. It is not a
permissively licensed binary release. Do not publish that history as an audited
release. No PyMuPDF code is used by the current application or tests.
